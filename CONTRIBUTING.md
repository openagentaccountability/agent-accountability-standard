# Contributing to the Agent Accountability Standard (AAS)

Thank you for your interest in contributing to the Agent Accountability Standard (AAS).

AAS is an open-source discussion draft independently conceived and initially authored by **Kay Yoo in 2026**, through Naru Advisory.

The project welcomes technical feedback, research perspectives, implementation experiments, and contributions from the broader AI community.

## 1. How to Contribute

Contributors are encouraged to:

- Open GitHub issues to identify technical gaps, security concerns, or opportunities for improvement.
- Propose enhancements to the specification, including agent identity, delegated authority, cryptographic attestations, and interoperability.
- Submit changes through pull requests.
- Provide supporting research, references, or implementation examples where appropriate.

For significant architectural changes, please open an issue for discussion before submitting a pull request.

## 2. Authorship and Attribution

AAS was independently conceived and initially authored by Kay Yoo.

The original specification is preserved through the repository's commit history and initial tagged release (`v0.2.1-draft`).

Subsequent contributors will be credited for their respective contributions through GitHub history and, where appropriate, project acknowledgments.

Contributing to AAS does not imply ownership of the entire project, authority over its governance, or endorsement by any affiliated organization.

## 3. Review and Governance

The project is currently maintained by its original author.

All proposed changes are subject to maintainer review before incorporation into the main specification.

Project governance may evolve as the community develops. Any future governance arrangements will be documented transparently.

## 4. Licensing

AAS is distributed under the Apache License 2.0.

By submitting a contribution, contributors agree that their contribution is provided under the project's existing license, unless explicitly agreed otherwise in writing.

Contributors must have the necessary rights to submit their work.

## 5. Project Status

AAS is an early-stage technical discussion draft.

It is not currently an adopted or formally ratified industry standard. Participation or contribution does not imply endorsement by any organization.
